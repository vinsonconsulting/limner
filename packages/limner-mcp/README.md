# @limner/mcp

Limner's MCP server. One TypeScript surface, three transports (Workers Streamable HTTP + stdio + `.mcpb` bundle), 18 tools wrapping `@limner/core`.

Built on the brain/hands split from D-RA-01: this is the *durable product surface* (the brain's hands for any MCP client, including Claude Desktop, LobeHub, the CMA agent itself per D-RA-12). Pipeline credentials live in Cloudflare Secrets; never travel to the client.

## Status

Phase 4 of the rebuild. Code lands by phase per [`docs/Limner_Cloudflare_CMA_Architecture.md`](../../docs/Limner_Cloudflare_CMA_Architecture.md); Phase 4 ships the server + OAuth + MCPB packaging. Phase 5 (`limner-cma-tools`) and Phase 7 (deploy) follow.

The `cf*` ops require the Workers transport (Cloudflare Images binding); the stdio transport returns an `unsupported_in_stdio` error for those.

### Asset delivery (PR D)

On the Workers transport, when a `GENERATED_BUCKET` (R2) **and** an `ARTIFACT_BASE_URL` are configured, the `limner_generate_*` image tools **store the generated bytes in R2 and return a URL** (a text content block + `structuredContent.url`) instead of inline base64 — large outputs (e.g. gpt-image-1) otherwise exceed the MCP message-size ceiling. The URL points at a public `GET /artifact/<key>` proxy on the same Worker; keys are unguessable UUIDs (capability URLs). When `ARTIFACT_SIGNING_KEY` is set, the returned URL additionally carries an HMAC signature + expiry (`?exp=<epoch>&sig=<b64url>`) — clients use the URL verbatim; `serveArtifact` rejects unsigned, tampered, or expired requests with `403`. On a **public https origin** the signing key is required: if it is missing the proxy **fails closed** (`503`) rather than silently serving unsigned URLs (a local `http://localhost` origin still serves capability-only). Objects are reaped by the same 30-day retention sweep as the compose artifacts. Without a delivery store (stdio/local, or Workers without the bucket), the tools keep returning inline base64 — backward compatible.

## Transports

### 1. Stdio (preview at v1 per D-RA-05 amendment)

For Claude Desktop, local dev, the `.mcpb` bundle, anywhere stdin/stdout JSON-RPC works.

```bash
# Build the package.
pnpm install --frozen-lockfile
pnpm -r build

# Run directly (the binary is wired via package.json#bin).
node packages/limner-mcp/dist/stdio.js

# Or via npx after a `pnpm publish` (Phase 6+).
npx -y limner-mcp
```

Env vars consumed at startup:

- `OPENAI_API_KEY` — for `limner_generate_dalle`
- `RECRAFT_API_KEY` — for `limner_generate_recraft` (remote mode)
- `LIMNER_DB_PATH` — local SQLite path (default `~/.limner/limner.db`)
- `LIMNER_SCHEMA_PATH` — schema source (default resolved relative to dist)

### 2. Workers Streamable HTTP (production, OAuth-protected)

Deployed via `wrangler deploy` (Phase 7). The server is wrapped by `OAuthProvider` so all `/mcp` requests require a valid OAuth 2.1 Bearer token.

```bash
# Local dev (binds D1 + KV; IMAGES needs the account to have it enabled).
cd packages/limner-mcp
wrangler dev --local

# MCP Inspector smoke (in another shell):
npx @modelcontextprotocol/inspector http://localhost:8787/mcp
```

OAuth endpoints exposed by the provider:

- `/.well-known/oauth-authorization-server` — RFC 8414 metadata
- `/oauth/token` — token issuance + refresh
- `/oauth/register` — RFC 7591 dynamic client registration
- `/authorize` — auto-approve in v1 dogfood (D-RA-12); explicit consent UI lands later

Bindings in `wrangler.toml`:

| Binding | Resource | Required |
|---|---|---|
| `DB` | D1 `limner-rasa-dev` | yes — memory + projects + sessions |
| `OAUTH_KV` | KV namespace | yes — workers-oauth-provider mandates this name |
| `IMAGES` | Cloudflare Images Transformations | optional — `cf*` compose ops require it |

Secrets (`wrangler secret put ...`):

- `OPENAI_API_KEY` — for `limner_generate_dalle`
- `RECRAFT_API_KEY` — for `limner_generate_recraft` (remote mode)

### 3. `.mcpb` bundle

Packed by `.github/workflows/build-mcpb.yml` on `mcpb-v*` tags. Includes the entire `dist/` tree + `node_modules/` + the `manifest.json` describing tools and env vars. Bundle size: ~11 MB compressed (WASM codec modules drive the bulk). The closure is the stdio runtime graph only — Workers-only deps live in `devDependencies` and are bundled by wrangler from source — and it is pure JS/WASM: local persistence uses Node's built-in `node:sqlite` (Node ≥ 22.13), so no platform-specific native addons ship (the boot smoke asserts both).

```bash
# Manual pack (matches the CI workflow — hoisted prod-only closure):
node scripts/pack-mcpb.mjs limner-mcp.mcpb

# Validate the manifest before packing:
./packages/limner-mcp/node_modules/.bin/mcpb validate packages/limner-mcp/manifest.json

# Boot-smoke the packed bundle:
pnpm smoke:mcpb limner-mcp.mcpb
```
